# AI漫剧系统各模块验收标准

> 来源：根据《AI漫剧系统需求规格说明书》整理，用于前端开发自测、前后端联调、测试验收和甲方确认。
>
> 验收口径：除特别说明外，所有功能均应在已登录、网络正常、接口返回正常的条件下完成；涉及 AI 生成的功能，前端验收重点为参数提交、状态展示、结果回填、异常提示和流程跳转，模型生成质量另按算法/接口验收口径确认。

## 1. 通用验收标准

| 验收编号 | 验收项 | 验收标准 |
|---|---|---|
| AC-COM-001 | 页面基础展示 | 页面进入后布局完整，无明显错位、遮挡、溢出、空白异常；主要按钮、输入框、列表、卡片、弹窗与原型风格一致。 |
| AC-COM-002 | 数据加载状态 | 首次进入页面时应有合理的加载态；接口返回空数据时展示空状态；接口异常时展示错误提示，不出现页面白屏。 |
| AC-COM-003 | 表单校验 | 必填字段、格式、长度限制、枚举选项等校验应在提交前完成；校验失败时给出明确中文提示。 |
| AC-COM-004 | 防重复提交 | 创建、保存、生成、导出等异步操作执行中，按钮应进入 loading 或 disabled 状态，避免重复点击造成重复请求。 |
| AC-COM-005 | 保存与草稿 | 需求中要求自动保存或暂存的数据，刷新或重新进入页面后应能恢复；保存成功/失败应有明确反馈。 |
| AC-COM-006 | 分页与搜索 | 列表类页面应支持分页、搜索、筛选；切换筛选或搜索关键词后页码应合理重置或保持有效。 |
| AC-COM-007 | 批量操作 | 进入批量模式后可选择、取消选择、全选当前页；执行批量删除/导出等操作前应有确认或明确提示。 |
| AC-COM-008 | 权限与登录态 | 未登录用户访问受保护页面应跳转登录；退出登录后清空本地登录态，不可继续访问项目内容。 |
| AC-COM-009 | 路由跳转 | 所有流程按钮应跳转到正确步骤；不满足前置条件时不得静默失败，应给出阻断原因。 |
| AC-COM-010 | 兼容性 | 主流程在目标浏览器中可正常操作；常见分辨率下页面布局不破坏。 |

## 2. 登录与账号模块

## 11. 非功能验收标准

| 验收编号 | 验收项 | 验收标准 |
|---|---|---|
| AC-NF-001 | 性能 | 常规列表、卡片、弹窗操作响应流畅；搜索、防抖、分页不造成明显卡顿。 |
| AC-NF-002 | 生成任务体验 | AI 生成类操作应有明确的生成中、成功、失败状态，不允许长时间无反馈。 |
| AC-NF-003 | 安全 | 密码、验证码、登录 token 等敏感信息不得明文暴露在页面或日志中。 |
| AC-NF-004 | 可靠性 | 接口失败、网络异常、空数据时页面不崩溃，能够显示可理解的提示。 |
| AC-NF-005 | 可维护性 | 模块代码结构清晰，公共组件可复用，页面样式不应大量依赖不可控的全局覆盖。 |
| AC-NF-006 | 可用性 | 主要流程按钮文案明确，错误提示能指导用户下一步操作。 |
| AC-NF-007 | 数据一致性 | 切换页面、刷新、返回上一流程后，已保存的数据应保持一致。 |
| AC-NF-008 | 文件导入导出 | 导入文件格式、大小、解析失败场景应有提示；导出文件名和内容结构应符合约定。 |
| AC-NF-009 | 响应式布局 | 主流分辨率下页面主体区域、卡片、分页、弹窗不遮挡、不溢出。 |
| AC-NF-010 | 浏览器兼容 | 在项目约定浏览器版本中完成主流程操作，无阻断性兼容问题。 |
