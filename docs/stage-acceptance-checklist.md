# 前端阶段验收清单

本文档用于说明当前前端项目的阶段性验收范围。当前目标是：mock 主流程可演示，后端接口边界可联调。本文档不表示所有后端能力、真实 AI 生成质量和最终工程导出已经完成。

## 1. 当前阶段定位

当前可验收范围：

- 基于 mock 数据跑通主制作流程。
- 页面状态、草稿保存、阶段跳转、基础导出可用。
- 主要生成能力已抽到 service 层，方便后续接后端。

当前不应作为已完成项：

- 真实 AI 生成质量。
- 后端异步任务轮询。
- 剪映工程导出。
- 成片合成导出。
- 资源库、音色库的完整 HTTP 写操作。

## 2. mock 主流程

推荐验收路径：

```text
登录 -> 项目列表 -> 新建项目 -> 文案输入 -> 剧本生成 -> 剧本分镜 -> 设定页 -> 分镜页 -> 视频页 -> 配音页 -> 完成页
```

| 模块 | 阶段结论 | 说明 |
| --- | --- | --- |
| 登录 | 基本可验收 | mock 密码登录可用，项目入口可进入 |
| 项目管理 | 基本可验收 | 新建项目后可进入编辑流程 |
| 文案页 | mock 可验收 | 剧本生成和剧本分镜已抽到 service，HTTP 待联调 |
| 设定页 | mock 可验收 | 资产管理、资源库导入、进入分镜校验可用 |

| 视频页 | mock 可验收 | 视频生成、批量生成、视频审核、进入配音校验可用 |

## 4. 关键验收规则

### 分镜进入视频

必须满足：

- 至少存在一个可见分镜。
- 图片生成模式下，所有可见分镜都有图片。
- 多参模式下，所有可见分镜满足多参必填项。
- 所有可见分镜完成分镜人工审核。

当前字段：

```ts
storyboardReviewed
```

旧字段 `isFavorite` 只作为历史草稿兼容读取。

### 视频进入配音

必须满足：

- 至少存在一个可见镜头。
- 所有可见镜头都有视频。
- 所有可见镜头完成视频人工审核。

当前字段：

```ts
videoReviewed
```

### 配音进入完成页

必须满足：

- 至少存在一个可见配音卡片。
- 所有可见台词都已生成音频。

页面按钮和路由守卫都使用同一套校验。

## 5. 后端接入边界

主要 service 边界：

```text
scriptGenerationWorkflow.service.ts      文案生成 / 剧本分镜生成
settingAssetGeneration.service.ts        设定素材图片生成
storyboardGeneration.service.ts          分镜图片生成 / 分镜放大
videoGeneration.service.ts               视频生成
dubbingGeneration.service.ts             配音生成
resourceLibrary.service.ts               资源库列表 / 导入
assetWorkflow.service.ts                 设定资产工作区同步
storyboardWorkflow.service.ts            分镜工作区同步 / 确认 / 生成
exportWorkflow.service.ts                完成页导出任务
```

生成任务 HTTP 边界详见：

```text
docs/generation-http-boundary.md
```

当前 HTTP 生成规则：

```text
创建任务 -> 读取 workspace 或 resultUrl -> 有结果则写回 -> 无结果但任务存在则提示任务处理中
```

后续真实异步任务需要补：

```text
创建任务 -> 轮询任务状态 -> 成功后刷新 workspace -> 写回 draft/store
```

## 6. 暂缓项

以下内容不纳入当前阶段完成验收：

1. 剪映工程导出。
2. 成片合成导出。
3. 后端真实异步任务轮询。
4. 后端真实 AI 生成质量验收。
5. 资源库 HTTP 写操作。
6. 音色库 HTTP 写操作。
7. 音色训练或声音克隆。
8. 团队协作、权限、计费、积分等非主流程管理能力。
9. DOC/DOCX 直接导入。
10. 项目导入导出与后端路径统一后的完整联调。

## 7. 推荐阶段结论

推荐表述：

```text
前端已完成基于 mock 数据的 AI 漫剧制作主流程，可支持从文案输入、剧本生成、设定管理、分镜生成、视频生成、配音生成到完成页汇总的阶段性演示。项目已整理主要 service/API 边界，便于后续接入后端接口和真实生成任务。
```

不建议表述：

```text
系统所有功能已经完成并可上线。
```
